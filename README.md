# Projeto QA - Testes de API com Postman

## Sobre o projeto
Projeto desenvolvido para praticar testes de API utilizando Postman.

## Objetivo
Validar endpoints de login, cadastro e consulta de usuários, aplicando conceitos de Quality Assurance.

## Ferramentas utilizadas
- Postman
- GitHub

## Cenários testados
- Buscar todos usuários
- Buscar usuário por Id
- Buscar usuário inexistente
- Criar usuário
- Atualizar usuário
- Excluir usuário

## Estrutura do projeto
- `Collection/` — pasta com a collection do Postman
- `Teste-case.postman_collection.json` — arquivo de collection exportado do Postman

## Como executar
1. Abra o Postman
2. Importe o arquivo `Teste-case.postman_collection.json`
3. Execute as requisições ou use o Collection Runner
